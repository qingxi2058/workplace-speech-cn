# workplace-speech-cn

中文职场表达 skill。适合在谈升职、加薪、拒绝不合理要求、应对甩锅、被当众批评、被逼离、谈赔偿这类场景里，快速产出能直接说出口的话术。

## 安装

```bash
npx skills add qingxi2058/workplace-speech-cn
```

## 这份 skill 解决什么问题

很多职场内容只会教人“高情商”，但真正难的是：

- 真话怎么说，才不会一开口就翻车
- 该争取、该拒绝、该澄清、该反击时，强度怎么拿捏
- 哪些事值得继续谈，哪些事应该直接留痕、谈条件、准备退出

这份 skill 的原则很简单：

- 不教撒谎
- 不教你吃亏式圆滑
- 不把明显越界的问题包装成“沟通技巧”

## 输出内容

默认会给出：

- 你应该说的话
- 为什么这样说有效
- 注意避免的词
- 如果对方继续施压

## 附带框架

仓库里额外提供了一份 [JT-SCALE.md](./JT-SCALE.md)：

- 用来判断一件事现在该说到多硬
- 适合做短视频、图文、直播讲解的固定框架

一句话理解：

- `JT1-JT2`：还能谈，重点是对齐
- `JT3-JT4`：开始有压迫，重点是切边界
- `JT5-JT7`：别再硬扛，重点是留痕、谈条件、止损
