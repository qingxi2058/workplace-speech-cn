## 简介

```
职场里很多话想说却不知道怎么开口——说软了被忽视，说硬了怕翻车。这个 skill 先判断你的处境该说到几级（JT Scale），再给你可以直接开口的话。覆盖加薪、拒绝加班、被甩锅、被 PUA、谈赔偿等高频场景，不教撒谎，不教圆滑，教你把真话说到能拿结果。
```

## Skill 介绍

```
职场里很多人不是不懂自己的处境，是不知道怎么开口。说软了被忽视，说硬了怕翻车，说多了像在解释，说少了像在认怂。

这个 skill 解决的，正是这件事。

工作方式

每次对话，先用 JT Scale 判断你的情况该说到几级——从需要对齐争取的 JT1，到需要留证据走流程的 JT7。判断完等级，再给你可以直接说出口的话，并解释为什么这样说有效，以及对方继续施压时怎么接。

覆盖场景

谈加薪升职、拒绝加班临时插单、被甩锅被当众批评、被 PUA 被拿格局压、谈赔偿离职补偿、收到空头承诺、被逼离职。

不做什么

不教撒谎，不教用圆滑掩盖诉求，不把该止损的事包装成"再努力沟通一下"。有些事值得谈，有些事该拿结果，有些事该止损——这个 skill 会帮你判断你现在是哪种情况。
```
